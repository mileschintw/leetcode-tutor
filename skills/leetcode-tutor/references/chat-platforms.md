# Chat platforms

How the tutor records an Attempt on a chat platform, where it can't save files: a chat app such as claude.ai, the Gemini app or ChatGPT, or this tutor pasted in as a prompt. It teaches the Session in full as usual; only the end of the Session differs. The Practice Log format is in [practice-log.md](practice-log.md).

## Contents

- End of a Session on a chat platform

- Pending page in the Mirror

## On a chat platform

You are on one when you can't save files to a folder the learner keeps. Check your tool list: you need a tool that creates or edits files, or one that runs shell commands. Tools that only read, list or search files don't count, so having them doesn't make a folder you can save to. Neither does a temporary sandbox, such as a code-execution environment, whose files are gone after the conversation. There is no Practice Workspace to find or create there: don't look for one, don't offer to create one, and don't ask the learner to choose between saving and printing. A Practice Workspace is a folder on the learner's computer, kept in git.

## End of a Session on a chat platform

Do steps 1 to 3 of "End of a Session: record the Attempt" in [practice-workspace.md](practice-workspace.md) (Key Takeaway, code and fields, including Need Review as [need-review.md](need-review.md) says), then one of these instead of its later steps:

- **With a Notion connector:** write the Attempt to the learner's Mirror as a pending page.
  1. Find the Mirror database. When the learner has given you its link (in this conversation or in the Project's instructions), fetch that and skip the search. Otherwise search Notion for `Practice Log`, and, when the learner has said which GitHub repository their Practice Workspace is on, for that repository's URL as well (`github.com/<owner>/<repo>`): it is in every Mirror page, so it finds a renamed Mirror too. Search mostly returns the Mirror's pages rather than the database: for a page, fetch it to find its parent database. A database is a Mirror when its properties include both `Problem ID` and `Pending`.
  2. Read which Practice Workspace each Mirror belongs to: its description names the repository (`One-way Mirror of the Practice Log at <repository>, …`). Notion's own connector doesn't show database descriptions, so otherwise read it from any of its pages' `GitHub` value, the part before `/tree/HEAD/`.
  3. Choose the Mirror:
     - When the learner has said which repository is theirs, leave out every Mirror of another repository.
     - When exactly one Mirror is left, use it.
     - When several are left, ask the learner which one, listing each one's title, link and repository, and suggest they put the link in their Project's instructions so you never have to search. Create nothing until they answer.
     - When none is left, don't create one: the Mirror is created by a push from the Practice Workspace. Print the Attempt block instead, as in the next case. Say it in these terms: you found no Mirror database in their Notion (none of their repository, when they named one), so nothing was saved there; a Mirror has to be pushed from their Practice Workspace first (with the `practice-log-mirror` skill), and after that, Attempts from a chat platform are saved to it as pending pages.

     In the chosen Mirror, create one page, as "Pending page in the Mirror" below says. Create nothing else, and change no other page or database: every other page is regenerated by the Mirror's push from the Practice Workspace.
  4. Reply with "Attempt saved to your Notion Mirror as pending", the page's link, the Mirror's repository when you know it, and the outcome, approach, mistakes, Key Takeaway and Need Review in a few lines. Say the next Import in their Practice Workspace brings it into the Practice Log, and invite the learner to correct anything.
- **Without one:** print the Attempt block below in one reply, and say that nothing was saved, so they should keep it: in their Practice Workspace, Import (the `practice-log-import` skill) can bring it into the Practice Log. Invite the learner to correct anything.

## The Attempt block

Two parts, each a path in backticks on its own line followed by a fenced block. First the Problem's `notes.md` as [practice-log.md](practice-log.md) defines it, holding only this Session's Attempt:

`problems/<source>/<slug>/notes.md`

```markdown
---
id: <Problem ID>
title: <title>
difficulty: <difficulty>
tags: [<tags>]
link: <link>
lists: []
need_review: <true or false>
need_review_reason: <reason, or empty>
---

## Key Takeaway

<Key Takeaway>

## Attempts

### <date> <approach>

- date: <date>
- mode: <mode>
- outcome: <outcome>
- approach: <approach>
- mistakes: <mistakes, or none when none were observed>
- language: <language>
- code: <date>-<approach slug>.<ext>
```

Then the code file, `problems/<source>/<slug>/<date>-<approach slug>.<ext>`, with the learner's final code in a block fenced with its language.

Leave out no field: write an empty value as the schema says. Write `mistakes: none` only when the Session showed no mistakes; a missing `mistakes` line would mean they aren't known, which never holds for a Session you taught. Translate nothing in the block, so it stays in the Practice Log format.

## Pending page in the Mirror

A page in the Mirror database with `Pending` checked. A Mirror push never updates or trashes it; the next Import brings its Attempt into the Practice Log, then moves the page to Notion's trash. Set its properties from the Session:

| Property | Value |
| --- | --- |
| Problem | the Problem's title |
| Problem ID | the Problem ID |
| Difficulty | `Easy`, `Medium` or `Hard`; empty when the source has none |
| Tags | the Problem's tags |
| Need Review | checked when `need_review` is `true` |
| Need Review Reason | `need_review_reason` when Need Review is checked, otherwise empty |
| Attempts | `1` |
| Last Attempt | the Attempt's date |
| Last Outcome | the Attempt's outcome |
| Link | the Problem's URL; empty when it has none |
| Pending | checked |

Leave `Lists` and `GitHub` empty. The page's content is the Attempt block, after this line:

```markdown
> Pending Attempt from a chat platform. The next Import in the Practice Workspace brings it into the Practice Log; until then, Mirror pushes leave this page alone.
```
