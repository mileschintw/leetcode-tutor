# v3 lives in a new repository; the v2 prompt repo is archived

Status: accepted. v3.0 shipped here on 2026-10-16, and `leetcode-tutor-prompt` was archived with a pointer to this repository.

v2 was a single copy-paste system prompt (`leetcode-tutor-prompt`). v3 is a different product: installable skills, a learner-owned Practice Log, Import and a Notion Mirror, packaged for several agent platforms. We started it in this new repository rather than evolving the old one, so v3 has a clean history and v2 users keep a stable, frozen prompt. The old repository gets a pointer to this one in its README and is then archived; the copy-paste prompt continues here, generated from the skill's `SKILL.md`.
